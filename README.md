# camilasabino.dev

Portfolio personal de [Camila Sabino](https://github.com/camilasabino).

- Sitio: https://camilasabino.dev
- Stack: [Astro](https://astro.build) → [Cloudflare Pages](https://pages.cloudflare.com/)
- Primer proyecto destacado: [Blendify](/projects/blendify)

## Desarrollo local

```bash
npm install
npm run dev
```

Build de producción:

```bash
npm run build
npm run preview
```

Ver [SETUP.md](./SETUP.md) para cuenta Cloudflare, dominio, Pages y email routing.
